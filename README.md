# LIA Scientific Poster Template
HTML template for a scientific poster based on Avignon University's LIA
(Laboratoire Informatique d'Avignon).

Based on the LaTeX template created by Vincent Labatut.

## Content
 - index.html: Main file with the poster content.

 - css/style.css: Main stylesheet file, with the core style definitions.
 - css/custom.css: Sample of a custom file with a handful of style definitions
   for specific sections. Use it to define styles for a specific poster, keeping
   them separate from the core styles, which simplifies reusing the template in
   the future.

 - img: Sample images used in the template.

 - pdf/sample_A4.pdf: Sample output in A4 size.
 - pdf/sample_A0.pdf: Sample output in A0 size.
